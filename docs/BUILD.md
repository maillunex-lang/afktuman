# Сборка и проверка

## Автоматическая проверка

GitHub Actions запускает Godot 4.4.1 на Ubuntu в headless-режиме: импорт проекта и короткий smoke test. Это **не** проверяет прозрачность Windows, DPI, клики, управление двумя окнами или Windows x64 экспорт.

## Windows x64

1. Установить Godot 4.4.1 stable и соответствующие export templates.
2. Открыть `godot/project.godot`.
3. Запустить сцену и проверить окно управления, click-through и позиционирование.
4. Создать папку `dist/` в корне репозитория.
5. Экспортировать пресет Windows Desktop в `dist/TumanPrototype.exe`.
6. Проверить запуск exe без редактора Godot и наличие нужного .pck (если не встроен).

Пресет подготовлен, но **Windows-бинарник пока не собран и не протестирован**. Не публиковать как релиз до GUI-тестов.

## Ручной чек-лист

- Прозрачность и отсутствие рамки.
- Оверлей не перехватывает клики, гараж принимает ввод.
- Скрыть/показать, FPS 30/15, распыление вкл/выкл, выход.
- Панель задач снизу/сбоку, несколько экранов, DPI 100/125/150%.
- После закрытия гаража процесс завершается.
