# Сборка и проверка

## Готовый архив

Открой [GitHub Actions](https://github.com/maillunex-lang/afktuman/actions/workflows/godot-check.yml) и скачай `TumanPrototype-Windows-x64` из раздела Artifacts успешного запуска. Распакуй оба файла в одну папку и запусти `TumanPrototype.exe` на Windows 10/11 x64.

## Проверка и локальный экспорт

Используй Godot 4.7.2 stable и соответствующие шаблоны экспорта. Выполни эти команды из корня репозитория. `godot` обозначает установленный исполняемый файл движка.

```sh
mkdir -p dist
godot --headless --path godot --editor --import --quit
godot --headless --path godot --quit-after 12
godot --headless --path godot --export-release "Windows Desktop" "$PWD/dist/TumanPrototype.exe"
```

В workflow импорт, запуск и экспорт завершаются ошибкой при появлении `ERROR:` в логах Godot, даже при коде выхода 0. На VPS проверены импорт, запуск без интерфейса, короткий запуск в виртуальном Linux-дисплее и экспорт Windows x64. Архив прошёл проверку целостности через `unzip -t`.

## Приёмка на рабочем столе Windows

- Видна техника на прозрачном фоне над панелью задач.
- Клик в области оверлея доходит до окна другой программы. Кнопки гаража принимают ввод.
- Кнопки скрытия, показа, 30/15 FPS, распыления и выхода работают. Закрытие гаража завершает процесс.
- Положение сохраняется при изменении разрешения, расположения панели задач и масштаба 100/125/150%.
- Замеры FPS, CPU и памяти выполнены в видимом и скрытом режимах.

Фактический запуск Windows EXE и приёмка по этому списку требуют графической Windows-сессии.
