# Prototype-001: Windows Desktop Overlay

## Цель

Доказать, что маленький 2D Туман отображается в прозрачном окне над панелью задач и не мешает Windows.

## Порядок

1. P001: прозрачное borderless окно Godot, позиция относительно рабочей области, безопасный выход.
2. P002: временная техника из примитивов, движение, разворот, распыление.
3. P003: надёжный способ открытия управления, затем click-through.
4. P004: компактный гараж и настройки FPS.
5. P005: DPI 100/125/150%, разрешения, фокус, fullscreen, 30/15 FPS.
6. P006: Windows x64 экспорт и запуск на чистой машине.

## Критерии приёмки

- Прозрачный фон действительно показывает рабочий стол.
- Окно не блокирует клики по другим приложениям после включения click-through.
- Есть независимый способ управления и выхода, даже при click-through.
- Оверлей корректно позиционируется при изменении разрешения и расположения taskbar.
- Нет критических ошибок запуска и падений.
- Тестовая сборка запускается без Godot Editor.

## Проверка P001 на Windows

1. Открыть `godot/project.godot` в Godot 4 и запустить F6/F5.
2. Проверить, что фон прозрачен и видна только техника.
3. Проверить положение у нижнего правого края доступной рабочей области.
4. Изменить положение/размер панели задач, разрешение и масштаб DPI: убедиться, что окно остаётся в рабочей области.
5. Проверить движение и разворот техники, Esc при фокусе окна.
6. Записать версию Godot, Windows, DPI, результат и ошибки.

**P003/P004 эксперимент:** отдельное окно управления создаётся первым; только затем на основном окне устанавливается `Window.FLAG_MOUSE_PASSTHROUGH`. Гараж пока постоянно открыт и имеет кнопки скрыть/показать Тумана, 30/15 FPS и выход. Закрытие гаража завершает приложение. Проверь на Windows, что второе окно действительно остаётся доступным и клики проходят сквозь основное. Если этого нет, считать P003 BLOCKED, а не DONE. Esc работает только когда окно имеет фокус.

## Ограничения текущей реализации

Сцена Godot и примитивный Туман являются начальным кодом. Прозрачность, click-through, взаимодействие двух окон, расположение окна, DPI и экспорт не подтверждены реальным Windows GUI тестом. Не переводить P001/P002 в DONE до проверки.
