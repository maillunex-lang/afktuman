# Туман: спрайты из пользовательского PNG

Источник: переданный пользователем архив `tuman_animation_assets.zip`, оригинал опрыскивателя, 1536×614, белый фон.

## Подключение
Скрипт `godot/scripts/overlay_demo.gd` автоматически использует:
1. `godot/assets/sprayer/atlas.png` (предпочтительно): 256×148, корпус сверху, три колеса снизу.
2. Или `godot/assets/sprayer/body.png` и `wheel_1.png` ... `wheel_3.png`.
3. Если текстур нет, используется временная векторная машинка.

Атлас подготовлен из архива пользователя, но бинарный PNG ещё **не закоммичен** в репозиторий. Нельзя считать замену графики завершённой до появления файла в GitHub и проверки Windows-сборки.

## Анимация
Колёса вращаются через `wheel_phase`, корпус движется по траектории патруля, спрайт зеркалится при развороте. Следующие этапы: распыление поверх спрайта, лёгкое покачивание корпуса, UI для настройки масштаба.

## Контроль качества
- Проверить прозрачность на тёмных и светлых обоях.
- Проверить положение колёс у панели задач, особенно при DPI 125–150%.
- Проверить разворот, вращение всех трёх колёс, паузу и click-through.
