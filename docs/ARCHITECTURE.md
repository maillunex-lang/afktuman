# Архитектура

Godot 4 / GDScript, один процесс. Модули будущей игры: Overlay, Patrol, Combat, Progression, Economy, Equipment, Loot, Stages, Save. В прототипе реализуется только окно и визуальный патруль.

Windows-specific функции изолировать в WindowsOverlayAdapter. Сначала пробовать встроенные DisplayServer и Window API. Для полноценного click-through понадобится проверка на Windows; нельзя одновременно полностью пропускать клики и полагаться на клики по спрайту как на единственный способ управления.

Пока нет отдельного процесса симуляции, сетевых сервисов или базы данных. В будущем расчёт наград не должен зависеть от FPS.
