# ТУМАН: Битва за урожай

Windows Desktop AFK RPG: маленький опрыскиватель Туман патрулирует поле над панелью задач Windows. Godot 4, GDScript, Clean Stylized 2D.

## Текущий статус

Prototype-001: проверка прозрачного Windows-оверлея. **Windows GUI и click-through пока не проверены.** Полная RPG не реализуется до подтверждения прототипа.

## Запуск исходников

Открыть каталог `godot/` в Godot 4. Сцена запуска задаётся в project.godot. На Windows проверить прозрачность, положение окна, клики и фокус. Для прототипа нажать Esc, чтобы выйти. Прозрачное окно в этой первой версии может принимать клики; это известное ограничение P001.
