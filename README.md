# ТУМАН: Битва за урожай

Windows Desktop AFK RPG: маленький опрыскиватель Туман патрулирует поле над панелью задач Windows. Godot 4, GDScript, Clean Stylized 2D.

## Текущий статус

Prototype-001: проверка прозрачного Windows-оверлея. **Windows GUI и click-through пока не проверены.** Полная RPG не реализуется до подтверждения прототипа.

## Запуск исходников

Открыть каталог `godot/` в Godot 4. Сцена запуска задаётся в project.godot. На Windows проверить прозрачность, положение окна, клики и фокус. В прототипе есть отдельное окно управления: скрыть/показать Тумана, переключить 30/15 FPS и выйти. Закрытие окна управления также завершает приложение. Основное окно получает флаг click-through после создания окна управления. Работу двух окон на Windows ещё необходимо проверить.
