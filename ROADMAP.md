## Текущее состояние

На VPS с Godot 4.7.2 проверены импорт, headless-запуск и графический старт в Linux через Xvfb. Исправлены типы координат и создание нативного окна гаража. Экспорт Windows x64 и целостность ZIP проверены. GitHub Actions настроен собирать и публиковать архив.

## Следующий шаг

Запустить экспорт на рабочем столе Windows и пройти [чек-лист](docs/BUILD.md#приёмка-на-рабочем-столе-windows). Записать версию ОС и результаты по прозрачности, кликам, DPI и производительности.
