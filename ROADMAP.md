## Текущее состояние

На VPS с Godot 4.7.2 проверены импорт, headless-запуск и графический старт в Linux через Xvfb. Исправлены типы координат и создание нативного окна гаража. Экспорт Windows x64 и целостность ZIP проверены. GitHub Actions настроен собирать и публиковать архив.

## Визуальный стиль

Выбран Clean Stylized 2D (вариант A), строго боковая проекция. По скриншоту Windows уменьшен масштаб техники с 0.48 до 0.40, высота окна 64 → 52 px. Для нижней панели задач добавлено перекрытие верхней границы на 14 px. На Windows проверить, не перекрывает ли сама панель задач часть рисунка и сохраняется ли click-through. PNG-атлас пользователя уже находится в `godot/assets/sprayer/atlas.png`; временный векторный рисунок остаётся запасным вариантом.

## Контрольный проход (18.11.2026)

- P002: плавный разворот на месте за 0.32 с вместо мгновенного зеркалирования. Центр машины не меняет позицию при развороте.
- P003: реализованы `StatusIndicator`, меню трея и экспериментальный Win32 helper для скрытия двух кнопок на панели задач. **Windows-проверка не завершена.**
- P004: гараж открывается из трея; требуется проверить закрытие, повторное открытие и выход.
- P005: 30/15 FPS реализованы; замеры CPU/RAM и DPI пока не проведены.
- P006: Windows x64 export и Releases настроены; окончательная приёмка на Windows не завершена.
- Godot 4.7.2 на VPS: импорт и headless smoke test после изменений прошли.
